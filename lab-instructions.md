# Lab Activity — About Me in React

## Given

`about-me.html`. Open it in a browser. That is the page you are reproducing.

## Task

Build the same page in a new React project, then replace the content with your own details.

## Instructions

1. Scaffold a new React project and get it running. Name the local project however you like.
2. Set up Tailwind CSS in it.
3. Reproduce the given page. Everything inside `<body>` belongs in your project; nothing outside it does.
4. Fix whatever breaks. The errors are the activity.
5. Once the page matches the original, replace the text with your own details.

## Constraints

- Everything you write goes in `src/App.jsx`. No new components, no new files.
- The generated project ships with styles of its own. They are not part of the page you were given.
- Same sections, same order, same classes, same structure. Text is the only thing that changes.
- No images.
- No curly braces `{ }` in your text.

## Submission

Create a GitHub repository named `CSIT340-Lab1-LastName`, using your own last name.

Push the project to it and submit the repository link.

## Done when

- The page loads with no error screen and a clean console.
- Side by side with `about-me.html`, the layout is identical.
- Every piece of text is about you.
